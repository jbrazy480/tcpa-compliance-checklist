# Contributing

Use Python 3.11 or newer. Install requirements-dev.txt in a virtual environment
and install this package with `pip install -e .`. Run `pytest` and the demo
before submitting changes. Keep tests offline and use fictional numbers only.

Cite primary sources for legal statements. Do not add state-specific rules.
Edit scripts/build_checklist.py and run it to regenerate both checklist formats.
Keep the root and packaged consent schemas identical. Document timezone data
provenance and preserve the third-party notice and license when updating it.
Never add credentials, customer records or real consent evidence.
